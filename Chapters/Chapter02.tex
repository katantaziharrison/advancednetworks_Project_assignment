\chapter{Related Work}
\label{ch:related-work}

\section{5G Security and the IMT-2030 Framework}

The selected 3GPP specification provides a technical
baseline for 5G security, including authentication,
key management, and subscriber identity protection
\citep{threegpp2022security5g}. It establishes mechanisms
against which proposed changes in future networks can
be considered. This project uses the specified edition
as its baseline and will identify the relevant provisions
for each comparison.

The ITU's IMT-2030 framework describes the intended
capabilities and usage scenarios of future mobile systems.
These include AI and communication, integrated sensing
and communication, and massive communication
\citep{itu2023imt2030}. The framework establishes the
direction of development, while the 3GPP specification
provides details of existing security mechanisms.
Together, these documents support a comparison between
established protections and envisioned capabilities.

\section{Security and Privacy in Proposed 6G Systems}

\citet{porambage2021roadmap} review security and privacy
challenges associated with envisioned 6G architectures,
applications, and enabling technologies. Their discussion
provides a broad foundation for identifying potential
threats and research directions. As an early roadmap,
the paper presents expectations that this project will
consider alongside more recent publications.

\citet{dealwis2026federated} examine federated learning
for 6G security. They discuss threats affecting distributed
learning and ways that federated learning could support
security across network components. Their survey informs
our analysis of AI-related security concerns, particularly
the relationship between protecting a learning process
and using that process for network protection.

ETSI's report on ISAC examines security, privacy,
trustworthiness, and sustainability. It identifies concerns
including unauthorized sensing, manipulation of wireless
signals, and access to sensitive sensing information
\citep{etsi2026isacsecurity}. These concerns provide a basis
for examining potential changes to access control,
security testing, and monitoring practices.

\section{Positioning of This Project}

The selected sources address different aspects of the
transition towards 6G, from existing security mechanisms
to proposed capabilities and emerging risks. This project
will organize these perspectives around the tasks performed
by cybersecurity practitioners.

The review will compare the three selected capability
areas using common criteria. For each area, it will record
the relevant 5G baseline, the proposed development,
the documented security concern, and the potential
implication for practice. This comparison will support
a critical discussion of what the literature establishes
and which conclusions remain dependent on future
implementation and evaluation.
